## 一、方法介绍

### 1.1 问题定义

本项目旨在利用A股市场约300只股票的分钟级高频Order Book数据，预测12分钟后的价格变化率（fret12）。形式上，对于股票 $i$ 在时刻 $t$，我们的预测目标为：

$$y_{i,t} = \frac{\text{midpx}_{i,t+12} - \text{midpx}_{i,t}}{\text{midpx}_{i,t}}$$

该问题属于典型的**金融时间序列预测**任务，具有高噪声、非平稳、长尾分布等特点。

### 1.2 整体框架

我们沿用了项目初始代码的模块化架构，包含以下组件：

| 模块 | 文件 | 职责 |
|------|------|------|
| 数据加载 | `dl.py` | 从HDF5文件读取逐日分钟级数据，按需加载必要列以优化内存 |
| 交易日历 | `tradingcalendar.py` | 管理交易日判断与日期范围查询 |
| 特征工程 | `feat.py` | 从原始数据生成47个预测特征，覆盖五大类别 |
| 模型定义 | `mdl.py` | 支持Ridge / MLP / LightGBM三种模型，含内存优化与自动采样 |
| 模型评估 | `eval.py` | 计算MSE、Pearson相关系数、R² |
| 主入口 | `meow.py` | 编排训练与评估流程 |

运行方式与初始代码保持一致：

```bash
python meow.py
```

### 1.3 模型方法

我们实现了三种可选模型：

1. **Ridge线性回归**（baseline）：原始项目中的默认模型，使用L2正则化的线性回归，α=0.5。

2. **MLP神经网络**：使用四层全连接网络（256→128→64→32），ReLU激活函数，Adam优化器，并采用early stopping和自适应学习率策略以防过拟合。

3. **LightGBM**（主力模型）：梯度提升决策树模型，实验中使用300棵树、63叶节点，具有较强的鲁棒性和特征交互捕捉能力，内存效率高，训练速度快。

所有模型均在特征输入前使用`StandardScaler`进行标准化处理，以消除不同特征量纲的影响并加速训练收敛。针对大规模数据（>200万行），`mdl.py`内置了随机采样策略以保证内存安全。

## 二、数据分析

### 2.1 数据概览

数据集覆盖2023年6月1日至2023年12月31日共七个月的交易日，每个交易日包含约300只股票的分钟级快照数据（约69,000条/日），原始数据包含62个字段，涵盖：

- **价格信息**：midpx（中间价）、lastpx（最新成交价）、open/high/low（区间内开盘/最高/最低价）
- **订单簿信息**：bid0-bid19 / ask0-ask19（买卖各档价格）、各档挂单数量（bsize/asize系列）、各档成交金额（btr/atr系列）
- **成交信息**：主买/主卖成交数量、金额、笔数
- **委托流信息**：add/cancel订单（买卖方向的数量、金额、笔数）、VWAD延迟指标

经过列级筛选，我们保留了36个与分析目标直接相关的字段，涵盖订单簿微观结构、交易流和委托流三个核心数据域。

### 2.2 目标变量分析（fret12）

- **分布特征**：fret12呈现典型的尖峰厚尾分布，均值接近于零，但极端值较为频繁。
- **自相关性**：fret12的一阶自相关系数接近于零，验证了市场的弱式有效性；但更高阶的矩（如波动率）表现出明显的自相关性和聚集效应。
- **日内模式**：开盘和收盘附近的价格变化率和波动率显著高于盘中时段，这与金融市场微观结构理论一致。

### 2.3 特征相关性分析

我们对baseline特征与fret12的相关性进行了分析：

| 特征 | 与fret12的Pearson相关性 |
|------|--------------------------|
| ob_imb0 | ~0.5% |
| ob_imb4 | ~0.8% |
| ob_imb9 | ~0.3% |
| trade_imb | ~1.0% |
| trade_imbema5 | ~1.2% |
| lagret12 | ~-2.5% |

- lagret12具有最强的单特征预测能力且呈负相关，体现了**短期的反转效应**。
- 单个特征的预测能力有限（<3%），需要通过多维特征组合和合理的模型才能达到有实用价值的预测水平。

## 三、创新点说明

### 3.1 特征工程创新

我们在原始6个特征的基础上系统性地扩展到**47个特征**，分为五大类别：

**（1）订单簿不平衡特征（13个）**

- `ob_imb0` / `ob_imb4` / `ob_imb9` / `ob_imb19`：不同深度的数量加权订单簿不平衡，越深档位反映越大资金的挂单意图。
- `ob_tr_imb0` / `ob_tr_imb4` / `ob_tr_imb9` / `ob_tr_imb19`：成交金额加权的不平衡指标，比数量加权更能反映大单/高价单的信息含量。
- `ob_spread` / `ob_spread9`：相对买卖价差，反映市场流动性和逆向选择风险。
- `ob_midpx_pos`：中间价在买卖价差中的相对位置，反映微观买卖压力。
- `ob_depth_ratio` / `ob_depth_ratio9`：近端深度占远端深度的比例，衡量流动性集中程度。

**（2）交易流特征（7个）**

- `trade_imb`：买卖成交量不平衡。
- `trade_imbema5` / `trade_imbema20` / `trade_imbema60`：不同半衰期的EMA平滑，捕捉多时间尺度的买卖压力趋势。
- `trade_turnover_imb`：成交金额加权的不平衡。
- `trade_count_imb`：成交笔数不平衡，反映算法交易意图。
- `trade_intensity`：总成交笔数，反映市场参与热度。

**（3）委托流特征（Add/Cancel）（8个）—— 新增板块**

- `add_imb` / `add_imbema5`：新增委托单的买卖不平衡。add订单反映尚未成交的潜在供需意图，是订单簿变化的前瞻性信号。
- `cxl_imb` / `cxl_imbema5`：撤单的买卖不平衡。高频撤单往往暗示做市商对当前定价的不认可，具有信息含量。
- `net_order_flow`：净委托流 = (买入add - 买入cancel) - (卖出add - 卖出cancel)，综合衡量主动委托方向。
- `cancel_rate`：撤单率，反映订单簿的稳定性和做市商信心。
- `add_trade_ratio` / `cxl_trade_ratio`：add和cancel量相对于成交量的比例。

**（4）价格动量特征（6个）**

- `bret1` / `bret5` / `bret12`：多时间尺度的回望收益率。
- `lagret1` / `lagret5` / `lagret12`：横截面标准化后的收益率（原始收益减去同interval均值），消除市场系统性波动。

**（5）波动率与区间特征（4个）**

- `price_range`：(high - low) / midpx，区间内价格波动幅度。
- `realized_vol5` / `realized_vol12`：不同窗口的已实现波动率，利用波动率聚集效应。
- `spread_ema12`：价差平滑值，捕捉流动性变化趋势。

**（6）成交量特征（4个）**

- `total_trade_qty` / `rel_trade_qty`：绝对和相对成交量。
- `buy_qty_ratio`：主动买入占比。
- `total_qty_ema12`：成交量EMA平滑。

**（7）横截面特征（5个）**

对`ob_imb0`、`bret12`、`total_trade_qty`、`add_imb`、`ob_spread`做横截面排名（percentile rank），将绝对指标转换为该股票在当前时刻的相对位置，帮助模型学习跨股票相对强弱。

### 3.2 模型创新

**（1）LightGBM作为主力模型**

原始代码使用Ridge线性回归（Pearson ~2%-3%）。我们引入LightGBM梯度提升树模型：
- **参数配置**：300棵树、63叶节点、max_depth=10、学习率0.05、max_bin=127
- **正则化**：L1 + L2正则化（reg_alpha=0.1, reg_lambda=0.1）
- **子采样**：行采样80%、列采样80%，增强泛化能力

LightGBM基于直方图的算法在训练速度和内存效率上远超MLP，能够高效处理大规模表格数据，并自动捕获特征之间的非线性交互。

**（2）内存优化与大规模训练支持**

针对全量数据（~850万样本）的训练需求，我们在`mdl.py`中实现了多层内存优化：
- 数据加载时仅选取必需的36列（从62列中筛选），减少约40%内存占用
- 特征矩阵使用float32存储
- 当训练数据超过200万行时自动随机采样，确保在常规硬件上稳定运行
- 及时释放中间变量并手动调用垃圾回收

**（3）多模型可配置架构**

提供Ridge/MLP/LightGBM三种模型选项，通过`modelType`参数灵活切换。

### 3.3 创新点的设计动机与理论依据

- **add/cancel委托流特征**：传统订单簿分析主要关注成交和挂单快照，但add/cancel事件包含更丰富的市场微观结构信息。实证研究表明，高频撤单行为与价格发现过程密切相关（Hasbrouck, 1991; Cao, Hansch & Wang, 2009），add订单的方向性偏差可预测短期价格走势。
- **多时间尺度特征**：短期价格动态是不同频率信息流的叠加。通过同时提供1/5/12分钟的回望收益率和不同半衰期的EMA指标，模型可以学习到不同频率信号的组合方式。
- **金额加权不平衡**：大额挂单比小额挂单包含更多关于未来价格方向的信息（Cont, Kukanov & Stoikov, 2014）。
- **横截面特征**：A股市场个股走势高度受市场整体影响。横截面排名将绝对指标转换为相对排名，有助于消除市场系统性波动的影响。

## 四、实验设计与结果分析

### 4.1 实验设置

| 配置项 | 值 |
|--------|-----|
| 模型 | LightGBM（300棵树，63叶，max_depth=10） |
| 训练集 | 2023/06/01 - 2023/11/30（123个交易日） |
| 测试集 | 2023/12/01 - 2023/12/29（21个交易日） |
| 训练样本量 | 8,548,841 → 采样200万（避免内存溢出） |
| 特征数 | 47 |
| 特征标准化 | StandardScaler（Z-score） |

### 4.2 实验结果

在21个交易日的独立测试集上：

| 指标 | 数值 |
|------|------|
| **Pearson 相关系数** | **0.0775 (7.75%)** |
| R² | 0.0059 |
| MSE | ~0.00 |

### 4.3 结果分析

- **Pearson 7.75%** 落在项目预期的5%-10%范围内，相比Ridge baseline（2%-3%）有**约3-4倍的相对提升**。在高噪声的金融高频预测场景中，这是一项显著改进。
- **R²接近零但为正**，说明模型捕获了微弱的预测信号——这在分钟级价格预测中是常见现象。金融市场高度有效，可预测成分极小。
- **LightGBM训练高效**：2M样本上完成300棵树训练仅需约22秒，远快于MLP（同等数据量需数十分钟）。
- 模型表现稳定，在全部21个测试交易日上未出现极端预测或崩溃情况。

### 4.4 消融分析设计

为进一步评估各组特征的贡献，我们设计了消融实验方案：

| 实验组 | 特征数 | 说明 |
|--------|--------|------|
| Baseline | 6 | 原始特征组（ob_imb0/4/9, trade_imb, trade_imbema5, lagret12） |
| +OrderBook | 19 | 增加订单簿深度特征 |
| +TradeFlow | 26 | 增加多尺度交易流特征 |
| +OrderFlow | 34 | 增加add/cancel委托流特征 |
| +Momentum | 40 | 增加多尺度动量特征 |
| +Volatility+CS | 47 | 增加波动率与横截面特征（全量） |

预期每组特征均有边际提升，其中委托流特征和波动率特征的边际贡献预计最大。

### 4.5 潜在改进方向

- **全量训练**：当前因硬件内存限制采样至200万，若使用更大内存或分布式训练，全量8.5M样本可能进一步提升效果。
- **神经网络架构优化**：引入残差连接、注意力机制或Transformer编码器。
- **时序模型**：使用LSTM/GRU/TCN显式建模时间依赖。
- **在线学习**：利用LightGBM的增量训练能力，实现模型滚动更新以适应市场变化。

### 4.6 总结

本项目基于MEOW初始框架，系统性地扩展了特征工程体系（6→47个特征），涵盖订单簿、交易流、委托流、价格动量、波动率和横截面六大维度。创新引入add/cancel委托流特征作为新增数据域，并以LightGBM作为主力模型实现高效训练。实验结果表明，**Pearson相关系数达到7.75%**，验证了特征扩展和模型选型的有效性。代码保持了与原始项目一致的模块化风格，并内置内存优化和采样策略以确保实用性。
